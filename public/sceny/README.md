# Sceny nagrane telefonem (splaty)

Tu trafiają pliki `.splat` / `.ply` / `.spz` z aplikacji do skanowania (Scaniverse, Polycam, Luma). Nazwy:

| plik | miejsce | brama |
|------|---------|-------|
| `opatowska.splat` | łuk Bramy Opatowskiej od strony miasta | — |
| `rynek.splat` | studnia na Rynku | 3 |
| `jakub.splat` | portal kościoła św. Jakuba | 4 |
| `piszczele.splat` | wylot Wąwozu Piszczele | 7 |
| `pieprzowki.splat` | punkt widokowy na Górach Pieprzowych | — |
| `zamek.splat` | pod skarpą zamku | 5 |
| `pimpo-limpo.splat` | górka saneczkowa przy św. Pawle | 7 |

Nagranie: 45–90 s wideo, powoli, po łuku wokół miejsca, ujęcia nakładają się, bez ludzi, bez słońca w obiektywie, bez zbliżeń. Eksport z aplikacji jako splat/ply; pliki 10–40 MB. Podgląd: `sceny/?plik=rynek.splat`.
